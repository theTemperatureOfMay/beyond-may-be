# 6. 공통·예외 처리

[전체 기능 명세](../feature-spec.md) · [백엔드 MVP 상태](../mvp.md) · [논의 필요](../open-questions.md)

## 상세 기능

### 6.1 오류 화면

#### 6.1.1 페이지 없음 (404)

- 적용 사용자: 전체 사용자

##### 상세 동작

- 존재하지 않는 라우트 접근 시 전체 화면 표시
- 문구: "페이지를 찾을 수 없어요 / 주소가 바뀌었거나 삭제된 페이지예요. 홈에서 다시 찾아보세요."
- 상단 홈 버튼으로 서비스 루트(/) 이동
- 유효하지 않은 코스 ID(4.1.1) 접근도 이 화면으로 통합
- 리소스 미존재(404) 응답 공통 사용

##### 백엔드·기획 참고

라우트 레벨 처리

#### 6.1.2 서버 오류 (500)

- 적용 사용자: 전체 사용자

##### 상세 동작

- 서버 오류(5xx) / 타임아웃 / 네트워크 오류 시 표시
- 문구: "일시적인 서버 오류가 발생했어요 / 문제를 확인하고 있어요. 잠시 후 다시 시도해 주세요."
- 주 버튼 '다시 시도': 실패한 요청만 재호출, 전체 새로고침 아님
- 보조 버튼(선택): 직전 단계 복귀, 기능별 지정
- 재시도 후 입력값(기간·선택 장소 등) 유지
- 자동 재시도 없음 (AI·과금 호출 중복 방지)

##### 백엔드·기획 참고

화면 내 상태 전환, 라우트 이동 아님

#### 6.1.3 요청 지연 (타임아웃)

- 적용 사용자: 전체 사용자

##### 상세 동작

- 타임아웃 경과 시 6.1.2 레이아웃 사용, 문구만 별도
- 문구: "시간이 오래 걸리고 있어요 / 다시 시도해 주세요."
- "서버 오류" 표현 미사용

##### 백엔드·기획 참고

[디자인 필요]

#### 6.1.4 만료된 링크

- 적용 사용자: 전체 사용자 (공유 링크 접속자)

##### 상세 동작

- 공유 링크 유효기간(3일) 경과 후 접근 시 표시
- 문구: "링크가 만료되었어요 / 코스를 만든 분에게 새 링크를 요청해 주세요."
- 홈 이동 경로 제공

##### 백엔드·기획 참고

백엔드가 공유 링크 만료 시각을 관리하고 만료 시 410 응답을 반환

#### 6.1.5 세션 만료

- 적용 사용자: 전체 사용자

##### 상세 동작

- 세션 토큰 만료·무효(401) 응답 시 오류 화면 미표시
- 로컬 스토리지 세션 정보 삭제 후 1.3.1 닉네임 입력 화면으로 이동
- 이동 시 "다시 로그인해 주세요" 안내

##### 백엔드·기획 참고

오류 아닌 정상 분기

### 6.2 공통 오류 정책

모든 API 호출 기능은 아래 매핑을 따른다. 개별 기능에서는 재시도 대상과 복귀
지점만 별도로 정의한다.

| 응답·상황 | 처리 | 사용자 액션 |
|---|---|---|
| 200·데이터 있음 | 정상 렌더링 | 없음 |
| 200·데이터 0건 | 6.3.1 빈 상태 | 기능별 대체 경로 |
| 400 잘못된 요청 | 인라인 안내 또는 6.1.2 | 입력 수정 |
| 401 세션 만료 | 6.1.5 | 자동 이동 |
| 403 권한 없음 | 6.1.2 문구 변형 | 홈 이동 |
| 404 리소스 없음 | 6.1.1 | 홈 이동 |
| 409 중복 참여 | 6.4.1 | 기존 지도 또는 신규 합류 선택 |
| 410·만료 | 6.1.4 | 홈 이동 |
| 5xx | 6.1.2 | 다시 시도 |
| 타임아웃 | 6.1.3 | 다시 시도 |
| 네트워크 오류 | 6.1.2 | 다시 시도 |

공통 규칙은 다음과 같다.

- 오류 화면은 404를 제외하고 라우트 이동이 아닌 화면 내 상태 전환으로 표시한다.
- `다시 시도`는 실패한 요청만 다시 호출하고 페이지 전체를 새로고침하지 않는다.
- 사용자가 입력하거나 선택한 값은 재시도 후에도 유지한다.
- 자동 재시도는 하지 않는다. 특히 AI 호출은 중복 요청을 금지한다.
- AI 요청 중에는 프런트엔드 전송 버튼을 비활성화한다. 공모전 MVP에서는 서버의
  영속 멱등성 키 저장까지는 적용하지 않는다.
- 오류 화면 상단에는 항상 홈 이동 경로를 유지한다.

| 기능 | 재시도 대상 | 보조 복귀 지점 |
|---|---|---|
| 1.1.1 세션 판별 | 세션 판별 API | 없음 |
| 1.1.2 질문 로딩 | 질문 조회 API | 메인 화면 |
| 1.2.2 성향 결과 계산 | 성향 결과 계산 API | 1.2.1 질문 진행 |
| 1.2.3 공유 카드 생성 | 카드 이미지 생성 | 1.2.2 결과 화면 |
| 1.3.1 세션 등록 | 세션 생성 API | 1.3.1 유지 |
| 2.1.2 추천 장소 조회 | 추천 장소 조회 API | 2.1.1 여행 기간 설정 |
| 3.1.0 AI 코스 생성 | 코스 생성 API | 2.3.1 선택 장소 목록 |
| 3.2.1 AI 코스 수정 | 코스 수정 API | 3.1.1 추천 코스 지도 |
| 4.1.1 팀 합류 | 코스 조회 API | 홈 |
| 4.3.3 방문 인증 | 방문 인증 API | 4.3.1 탐험 지도 |
| 4.4.1 주변 장소 추천 | 주변 장소 API | 4.3.1 탐험 지도 |
| 5.x 기록 조회 | 각 조회 API | 해당 탭 유지 |

### 6.3 빈 상태

#### 6.3.1 공통 빈 상태

- 적용 사용자: 명세에 별도 기재 없음

##### 상세 동작

- 0건 정상 응답 시 표시하며 오류로 취급하지 않는다
- 구성: 안내 문구 + (선택) 보조 문구 + (선택) 행동 유도 버튼
- 오류 화면과 시각적으로 구분 (오류 아이콘·코드 미사용)

##### 백엔드·기획 참고

단일 컴포넌트를 문구 변형으로 재사용

기능별 기본 문구는 다음과 같다.

| 위치 | 문구 | 보조 액션 |
|---|---|---|
| 2.1.2 추천 0개 | 추천 장소를 준비 중이에요 | 전체 장소 목록 보기 |
| 2.2.2 카드 소진 | 더 이상 추천 장소가 없습니다 | 선택 완료 |
| 4.4.1 주변 추천 0개 | 주변에 추천 장소가 없습니다 | 없음 |
| 5.1.1 진행 중 코스 없음 | 아직 탐험 중인 코스가 없습니다 | 코스 만들기 |
| 5.1.2 완료 코스 없음 | 아직 완료한 코스가 없습니다 | 없음 |
| 5.2.1 방문 기록 없음 | 아직 방문 인증한 장소가 없습니다 | 없음 |
| 5.2.2 밝힌 지도 없음 | 아직 밝힌 곳이 없어요 | 없음 |

### 6.4 중복 참여 차단

#### 6.4.1 중복 참여 차단

- 적용 사용자: 전체 사용자 (공유 링크 접속자)

##### 상세 동작

- `BEFORE` 또는 `ONGOING`인 활성 참여가 있는 상태에서 다른 공유 링크로 합류 시도 시 전체 화면 표시
- 문구: "이미 참여 중인 지도가 있어요 / 한 번에 하나의 지도에만 참여할 수 있어요. 새 지도에 참여하려면 먼저 기존 지도에서 나가야 해요."
- 선택지1 기존 지도로 이동: 4.2.1로 이동, 신규 합류 취소
- 선택지2 나가고 새 지도 참여하기: 확인 다이얼로그 표시 후 기존 세션 이탈 → 신규 합류 → 4.2.1 이동
- 확인 다이얼로그: "기존 지도에서 나갈까요? / {기존 방문 기록 처리 결과}"
- 이탈 처리 실패 시 6.1.2 표시

##### 백엔드·기획 참고

근거: 5.1.1 동시 진행 1개
이탈해도 기존 참여와 방문 기록은 보존
파괴적 동작, 확인 필요

### 6.5 공통 UI 요소

#### 6.5.1 스크롤 인디케이터 (TAB ▼)

- 적용 사용자: 명세에 별도 기재 없음

##### 상세 동작

- 하단에 추가 콘텐츠가 있음을 알리는 시각 표시
- 탭 시 다음 섹션으로 스크롤 이동하는 버튼으로도 동작
- 스크롤 하단 도달 시 숨김
- 스크롤할 콘텐츠 없는 화면에서는 미노출

##### 백엔드·기획 참고

접근성 라벨 필수

#### 6.5.2 로딩 표시

- 적용 사용자: 명세에 별도 기재 없음

##### 상세 동작

- 화면 전환 동반 요청: 전용 로딩 화면
- 부분 갱신 요청: 스켈레톤/인라인 인디케이터
- 예상 10초 이상 요청: 경과 시간별 안내 문구 전환
- 취소 가능 요청: 취소 경로 제공

##### 백엔드·기획 참고

적용: 1.2.3 / 2.1.2 / 3.1.0

#### 6.5.3 토스트

- 적용 사용자: 명세에 별도 기재 없음

##### 상세 동작

- 즉시 확인 가능한 짧은 피드백 (링크 복사 완료, 반경 외 인증 시도 등)
- 흐름을 중단시키지 않는 경우 오류 화면 대신 사용

##### 백엔드·기획 참고

- 별도 참고 사항 없음
