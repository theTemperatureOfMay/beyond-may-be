### 3.1 코스 확인

#### 3.1.0 AI 코스 생성

- 적용 사용자: 닉네임 세션 사용자

##### 상세 동작

- 2.3.2 선택 완료 시 선택 장소 ID 배열·순서·여행 기간·세션 ID를 서버에 전송하여 AI 코스 생성 요청
- AI는 담은 장소 전체를 대상으로 최적 방문 순서와 동선을 계산하며, 코스를 1개 생성
- 요청 중 전용 로딩 화면 표시, 경과 시간에 따라 안내 문구 단계 전환
- 로딩 중 취소 시 요청 취소 후 2.3.1 선택 목록으로 복귀
- 생성 완료 시 3.1.1 추천 코스 지도로 이동
- 오류 처리: 6.2 공통 오류 정책에 따른다 (재시도 대상: 코스 생성 API / 보조 복귀 지점: 2.3.1)

도보 경로 → TMAP API

#### 3.1.1 추천 코스 지도 보기

- 적용 사용자: 닉네임 세션 사용자 (코스 미확정)

##### 상세 동작

- AI 생성 코스 수신 후 자동 진입, 또는 확정 코스 없는 세션의 직접 접근 시 렌더링
- 지도 위에 코스 순서 번호별 핀 마커와 이동 경로 폴리라인 표시
- 초기 뷰포트: 코스 전체가 화면 안에 들어오도록 자동 줌 레벨 설정
- 하단 코스 요약 패널: 총 장소 수, 첫 번째 장소명 표시
- 코스 순서 핀이 밀집하는 경우(10곳 이상) 마커 클러스터링 또는 오프셋 처리
- 지도 라이브러리: Kakao Maps API
- 지도 렌더링 실패 시: 텍스트 기반 코스 목록 폴백 화면 표시

##### 백엔드·기획 참고

코스 데이터 없음 / API 오류 시 장소 재선택 유도
→ 6.2 참조

### 3.2 코스 수정

#### 3.2.1 AI 코스 수정 요청

- 적용 사용자: 닉네임 세션 사용자 (코스 미확정)

##### 상세 동작

- 'AI에게 수정 요청' 버튼 클릭 시 텍스트 입력 모달 표시
- 사용자가 수정 요청 사항 자유 입력 후 전송 시 현재 코스 데이터와 함께 AI API 호출
- 요청 중 로딩 인디케이터 표시
- 수정 결과는 미리보기로 표시한다.
- 추천 키워드 칩 제공, 선택 시 입력창에 자동 입력
- 응답 수신 시 수정된 코스를 지도 및 타임라인에 표시하고 '이 코스로 변경' / '원래 코스 유지' 버튼 제공
- 수정 요청 최대 횟수: 2번
- 횟수 초과 시: 직접 수정(3.2.2) 유도 안내 표시
- 입력 텍스트 최대 길이: 150자
- AI 응답 오류 시: 6.2 참조

##### 백엔드·기획 참고

수정 횟수(2회) 관리 주체 → 서버의 Course별 카운트

입력 텍스트 최대 길이 → 150자

(추천 문장 or 키워드 넣어두는 방향)

#### 3.2.2 직접 코스 수정

- 적용 사용자: 닉네임 세션 사용자 (코스 미확정)

##### 상세 동작

- '직접 수정' 탭 또는 버튼 클릭 시 편집 모드 진입
- 코스 내 장소 항목을 드래그앤드롭으로 방문 순서 변경 가능
- 항목 우측 삭제 버튼 클릭 시 해당 장소 코스에서 제거
- 순서 변경 또는 삭제 시 지도 폴리라인 및 타임라인 즉시 재렌더링
- 최소 장소 수 미달 시: 개별 삭제 버튼 및 '수정 완료' 버튼 비활성화 + 하단 안내 문구 상시 표시
- 최소 장소 수는 여행 기간에 따라 달라진다.
- 변경 이력 되돌리기 기능 제공 여부: 제공
- 되돌리기(↺): 직전 변경 1건씩 순차 취소, 편집 시작 시점까지 되돌리며 되돌릴 이력이 없으면 버튼 비활성
- 장소 추가 시 이미 코스에 포함된 장소는 검색 결과에서 제외하며, 선택한 항목은 시각적으로 구분 표시

##### 백엔드·기획 참고

최소 장소 수 → 여행 기간별 기준을 적용한다.

당일치기 : 3개
1박 2일 기준 : 5개
2박 3일 기준 : 7개
3박 이상 기준 : 20개

변경 이력 되돌리기 기능 제공 여부 → 제공

### 3.3 코스 확정 및 공유

#### 3.3.1 코스 확정

- 적용 사용자: 닉네임 세션 사용자 (코스 미확정)

##### 상세 동작

- '코스 확정하기' 버튼 클릭 시 재확인 다이얼로그 표시 ("확정 후에는 코스 수정이 불가합니다. 확정하시겠습니까?")
- 확인 클릭 시 현재 코스 데이터 서버 저장 및 상태를 draft → confirmed로 변경
- [Before] 코스 상태: draft / 수정 버튼 활성 / 확정 버튼 활성
- [After] 코스 상태: confirmed / 수정 버튼 비활성(숨김) / 공유 링크 생성 버튼·탐험 시작 버튼 활성화
- 확정 후 코스 수정 시도 시: "확정된 코스는 수정할 수 없습니다" 표시
- 다른 참여자가 합류하기 전에는 확정 취소(재설계 진입) 기능을 제공한다.
- 다른 참여자가 합류한 뒤에는 확정된 코스를 취소하거나 수정할 수 없다.

##### 백엔드·기획 참고

핵심 상태 분기점

확정 취소(재설계 진입) → 다른 참여자가 합류하기 전 제공

혼자/팀 모드를 구분하지 않으며 모든 코스는 1인 팀을 포함한 팀 구조를 사용

AI 코스 생성 성공 시 courseId를 발급하고 draft로 저장한 뒤 확정 요청에서 confirmed로
전환

#### 3.3.2 코스 공유 링크 생성

- 적용 사용자: 닉네임 세션 사용자 (코스 확정)

##### 상세 동작

- 코스 확정 후 활성화된 '공유 링크 생성' 버튼 클릭 시 서버에서 고유 공유 URL 생성
- 공유 URL 형식: `https://[도메인]/explore/[코스ID]`
- 생성된 링크를 플랫폼 공유 시트(카카오톡 / 링크 복사)로 전달 가능
- 링크 복사 완료 시 "링크가 복사되었습니다" 토스트 표시
- 공유 링크 유효 기간: 3일
- 공유 URL은 Course ID로 조합하며 별도 URL 문자열은 저장하지 않음
- 재발급 시 같은 URL을 유지하고 만료 시각만 다시 3일 뒤로 연장
- 코스 미확정 상태에서 버튼 비활성

##### 백엔드·기획 참고

공유 링크 유효 기간 → 3일

서버가 Course의 공유 만료 시각을 저장하고 만료된 링크 합류를 거부
