# ADR-0008 추천 상태를 서버에 누적하고 반응은 회차별로 전송한다

가입 전 검사 결과와 현재 카드·되돌리기 이력은 프런트엔드 상태로 두되, 재접속에 필요한
현재 추천 세트와 확정 반응은 서버가 보존한다. 추천은 회차당 20곳을 제공하고, 현재
회차 종료 시 최소 선택 수를 충족하지 못하면 이미 노출한 장소를 제외한 다음 20곳을
같은 추천 세트에 누적한다. 좋아요·싫어요는 회차가 끝날 때마다 그 회차 단위로 일괄
전송한다.

이 결정은 모든 추천 카드를 한 번만 제공하고 전체 종료 후 반응을 전송하던
[ADR-0002](0002-client-server-state-ownership.md)를 대체한다.

### 영향 대상

- 수정: 장소 선택 기능 명세, 백엔드 아키텍처, 백엔드 MVP 상태
- 후속 구현: 추천 조회·회차별 반응 API, 추천 세트 저장 모델과 관련 테스트
- 확인했지만 변경하지 않음: 현재 고정 응답 Controller·DTO·Service
- 미해결: API request/response 상세 계약

### 변경 영향 검사

- 검사: `change-impact-review`
- 결과: 문서 정합성 통과, API·저장 로직 후속 구현 필요
- 근거: 관련 제품·아키텍처·ADR·코드 대조, 제품 지식 베이스 검증 통과,
  `git diff --check` 통과
