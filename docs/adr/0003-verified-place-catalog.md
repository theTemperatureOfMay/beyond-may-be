# ADR-0003 검수된 장소 DB를 런타임 정본으로 사용한다

AI 장소 추천, 장소 상세, 코스 생성과 탐험 중 주변 추천은 동일하고 검수된 장소
정보를 사용해야 한다. 지도 경로 계산과 초기 장소 수집은 서로 다른 외부 시스템의
책임이다.

### 현재 상태

이 ADR의 장소 정본·AI 선별·검수 원칙은 계속 유효하다. 아래 `결정`에 기록된
Kakao Maps의 지도·경로 제공자 책임만
[ADR-0009](0009-kakao-map-tmap-walking-route.md)가 대체한다. 현재 지도·경로
제공자 경계는 ADR-0009를 따른다.

### 배경

AI 장소 추천, 장소 상세, 코스 생성과 탐험 중 주변 추천은 동일하고 검수된 장소
정보를 사용해야 한다. 지도 경로 계산과 초기 장소 수집은 서로 다른 외부 시스템의
책임이다.

### 결정

- 런타임 장소 정본은 PostgreSQL의 `places`다.
- AI는 DB에 존재하는 장소를 선별하며 신규 장소나 임의 ID를 생성하지 않는다.
- 한국관광공사 OpenAPI는 초기 광주 장소 수집에만 사용한다.
- Kakao Maps API를 통한 지도·경로·거리·이동시간 계산은 프런트엔드가 담당하며
  백엔드는 폴리라인과 계산 결과를 저장하지 않는다.
- 5·18 관련 정보는 AI 생성 문구가 아니라 검수된 장소 설명에 포함한다.

### 검토한 대안

- AI가 런타임에 새로운 장소를 생성하는 방식은 사용하지 않는다.
- 외부 장소 제공자를 런타임 정본으로 사용하는 방식의 비교 근거는 기록되지 않았다.

### 영향

- 추천과 코스에 사용하는 모든 장소 ID는 서버 DB 존재 여부를 검증해야 한다.
- 장소 수집과 검수 절차가 런타임 요청 처리와 분리된다.
- 경로 API가 실패해도 텍스트 코스 목록으로 대체할 수 있지만 서버가 경로 결과를
  복구해 주지는 않는다.

### 영향 대상

2026-08-09에 ADR-0009가 이 ADR 전체를 대체하는 것처럼 보이던 상태와 참조 표현을
정정했다. 장소 정본·AI 선별·검수 원칙에는 새로운 결정을 추가하지 않았고, 이 ADR의
당시 지도·경로 제공자 결정은 역사로 보존한다.

- 변경 유형: `architecture`
- 변경한 문서: ADR-0003의 현재 상태와 ADR-0009의 부분 대체 관계
- 이번 정정에서 추가 변경하지 않은 대상: 장소 선택·코스 설계 기능 명세, 백엔드
  아키텍처, 백엔드 MVP 상태와 제품 논의 필요. 현재 장소 정본과 지도·경로 제공자
  구분에 일치한다.
- 수정이 필요한 스킬·코드·테스트: 없음. 현재 백엔드에는 지도·경로 제공자 연동이
  구현되지 않아 이번 기록 정정으로 바뀌는 실행 동작이 없다.
- 미해결 항목: TMAP 연동 상세 계약과 프런트엔드 후속 구현. ADR-0009와 제품 논의
  필요 문서에서 추적하며 이번 대체 관계 정정을 막지는 않는다.
