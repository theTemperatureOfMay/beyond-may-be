# ADR-0002 임시 화면 상태와 재접속 상태의 소유권을 분리한다

성향 검사와 장소 스와이프에는 사용자가 작성 중인 화면 상태가 많지만, 추천 결과와
확정 코스처럼 재접속·공유·기록에 필요한 정보도 존재한다.

### 배경

성향 검사와 장소 스와이프에는 사용자가 작성 중인 화면 상태가 많지만, 추천 결과와
확정 코스처럼 재접속·공유·기록에 필요한 정보도 존재한다.

### 결정

- 가입 전 성향 결과, 현재 카드, 되돌리기 이력과 일괄 전송 전 반응은 프런트엔드 로컬
  상태로 관리한다.
- 사용자 세션, 현재 추천 세트, 좋아요·싫어요 최종 결과, 코스, 탐험과 방문 기록은
  서버가 PostgreSQL에 보존한다.
- 스와이프 반응은 모든 카드를 처리한 뒤 한 번에 서버로 전송한다.

### 검토한 대안

화면 진행 상태 전체를 서버에 저장하는 방식의 비교 근거는 기록되지 않았다.

### 영향

- 화면 전용 상태를 위한 API와 테이블을 만들지 않는다.
- 브라우저를 바꾸면 일괄 전송 전 상태는 복구되지 않을 수 있다.
- 서버에 저장된 추천 결과와 코스는 같은 세션의 재진입과 공유 흐름에서 정본이 된다.
