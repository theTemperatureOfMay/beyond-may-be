# 커밋 컨벤션

커밋 메시지의 첫 줄은 다음 형식을 따른다.

```text
<tag> : <제목>
```

- `tag`는 아래 허용 목록에서 고른다.
- `tag`는 영문 소문자로 작성한다.
- 제목은 한글로 간결하게 작성한다. API, 클래스명 등 고유명사는 원문을 사용할 수 있다.
- 제목 끝에는 마침표를 붙이지 않는다.

## 허용 태그

| 태그 | 용도 |
|---|---|
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `refactor` | 기능 변경 없는 코드 구조 개선 |
| `docs` | 문서 작성·수정 |
| `test` | 테스트 작성·수정 |
| `style` | 동작 변경 없는 코드 형식·스타일 수정 |
| `perf` | 성능 개선 |
| `ci` | CI/CD 설정·워크플로 수정 |
| `chore` | 빌드·의존성·개발 환경 등 기타 작업 |
| `revert` | 이전 커밋 되돌리기 |

## 예시

```text
feat : 여행 코스 추천 기능 추가
fix : 로그인 토큰 만료 오류 수정
docs : 커밋 컨벤션 문서화
```
