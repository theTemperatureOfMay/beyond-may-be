# 지속 가능한 학습

기본 저장 경로는 프로젝트 루트의 `.dev/learning/teach-me.md`다. 사용자가 다른 경로를
명시하면 그 지시를 우선하되, 개인 학습 내용을 승인 없이 공유 저장소에 쓰거나 커밋하지
마라.

## 기존 기록으로 이어가기

기본 파일이 있으면 주제 제목을 먼저 확인하고 현재 주제와 관련된 섹션만 읽어라. 이미
검증된 내용은 다시 가르치지 말고 다음 학습 방향에서 이어가라. 현재 대화에서 사용자가
밝힌 이해가 기존 기록과 다르면 현재 설명을 우선하고, 이번 세션에서 다시 검증한 뒤
기록 갱신 후보로 다뤄라.

## 기록 후보 판단하기

다음 순서로 후보를 판단하라.

1. **학습 기록**: 사용자가 중요 개념을 자기 말로 설명하거나 새 사례에 적용했거나 힌트
   없이 해결했다면 현재 이해와 다음 학습 방향을 한두 문장으로 기록한다. 기존 지식의
   깊이를 직접 밝혔다면 그 범위도 기록한다. 잘못된 이해를 수정했다면 수정 전 혼동을
   함께 남겨 다음에 같은 지점을 확인할 수 있게 한다.
2. **용어집**: 사용자가 용어를 올바르게 사용한 증거가 있을 때만 한두 문장으로 정의한다.
   대표 용어 하나를 선택하고 피해야 할 별칭이 있으면 함께 표시한다.
3. **자료**: 이번 학습에 실제 사용한 책, 논문, 공식 문서, 인정받는 전문가 또는 실력
   검증 공동체 중 신뢰도 높은 자료만 남긴다. 다루는 범위와 참고할 시점을 덧붙인다.
   사용하지 않은 자료를 채우기 위해 추가하지 않는다.

설명만 제공했고 사용자의 이해를 검증하지 못했다면 학습 기록과 용어집 후보가 아니다.
각 범주에 후보가 없으면 무엇이 부족한지 기록 생략 이유로 짧게 설명하라.

## 파일 형식과 갱신

파일은 주제별로 다음 네 섹션을 사용한다.

```markdown
## 주제

### 학습 기록
- YYYY-MM-DD — 완료 또는 부분: 현재 이해와 확인 근거

### 용어집
- 대표 용어: 정의

### 자료
- 자료명: 범위와 참고할 시점

### 다음 학습 방향
- 다음에 확인할 내용
```

중단, 일시정지 또는 주제 전환 시 저장하는 항목은 `부분`으로 표시하라. 새로운 이해가
기존 기록을 대체하면 이전 항목을 삭제하지 말고 `대체됨: YYYY-MM-DD`로 표시한 뒤 새
항목을 추가하라. 후보가 없는 섹션을 채우기 위해 빈 항목을 만들지 마라.

## 저장 승인 받기

1. 먼저 대화에 복사 가능한 초안을 제공하라.
2. 정확한 경로와 최종 저장 내용을 보여주고 사용자의 명시적 승인을 요청하라.
3. 명시적 승인을 받은 뒤에만 파일을 생성하거나 수정하라.
4. 승인 전에는 파일을 수정하지 마라. 승인을 받지 못하거나 사용자가 거절하면 대화
   초안만 유지하라.
5. 기록 후보가 없으면 빈 파일을 만들지 마라.
