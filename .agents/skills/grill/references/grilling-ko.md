# grilling

 계획·결정·아이디어를 사용자에게 집요하게 질문하여 검증한다. 사용자가 자신의 생각을 압박 검증하고 싶어 하거나 'grill' 관련 트리거 문구를 사용할 때 사용한다.
---

공유된 이해에 도달할 때까지 이것의 모든 측면을 집요하게 질문한다. 결정 트리의 각 가지를 따라가며 결정 간 의존성을 하나씩 해결한다. 각 질문에는 추천 답변을 제시한다.

질문은 한 번에 하나씩 제시하고, 계속하기 전에 각 질문에 대한 답변을 기다린다. 여러 질문을 한꺼번에 제시하면 혼란스럽다.

환경(파일 시스템, 도구 등)을 탐색하면 알 수 있는 사실은 사용자에게 묻지 말고 직접 확인한다. 다만 결정은 사용자의 몫이므로 각각 사용자에게 제시하고 답변을 기다린다.

사용자가 공유된 이해에 도달했다고 확인하기 전에는 그 내용을 실행하지 않는다.
