# Claude Code 연결 파일

저장소 루트를 기준으로 `.agents/skills/gh-create-project-pr/SKILL.md`를 끝까지 읽고 그 문서를 이 스킬의 유일한 실행 규칙으로 따르라.

원본 파일을 읽을 수 없으면 Pull Request 생성을 진행하지 말고 사용자에게 알려라.
